# paddy-trade-calculator
paddy-trade-calculator
Features included
1. Business inputs
- Number of paddy packets.
- Purchase price per packet.
- Two different selling prices.
- Handling, weighing, Hamali and Dalali charges.
2. Loan configuration
- Bank annual interest rate.
- Friend's monthly interest rate (₹ per ₹100).
- Loan amount.
- Simple interest or reducing-balance EMI calculation.
3. Automatic calculations
- 5-month and 10-month scenarios (customizable).
- Total investment and sales.
- Gross profit and net profit.
- Total borrowing interest.
- Break-even selling price.
- Profit per packet.
4. Business-friendly design
- Responsive mobile layout.
- Colour-coded financial sections.
- Comparison tables.
- Print-friendly report.
- Instant recalculation when inputs change.
How to run it
1. Download the HTML file.
2. Open it in Chrome, Edge or Safari.
3. Change the inputs.
4. View your updated profit calculations instantly.
How to deploy it
You don't need React, Node.js, npm or a backend.

You can deploy this single HTML file using:
- Netlify
- Cloudflare Pages
- GitHub Pages (upload as index.html).
Important: I've set simple interest on the full loan amount as the default, matching our earlier calculations. You can switch to reducing-balance EMI to compare actual loan repayment economics. Bank charges, taxes and other expenses must still be added separately.

My recommendation is to use this as your first version of the business calculator. It gives you a useful foundation for evaluating each paddy purchase before committing your money.
